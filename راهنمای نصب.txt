راهنمای نصب داشبورد روی هاست

1. فایل ZIP را در File Manager هاست آپلود کنید.
2. وارد پوشه public_html شوید. در برخی هاست‌ها نام این پوشه www یا htdocs است.
3. فایل ZIP را داخل همان پوشه Extract کنید.
4. بررسی کنید فایل index.html مستقیماً داخل public_html قرار گرفته باشد، نه داخل یک پوشه اضافی.
5. آدرس دامنه را در مرورگر باز کنید.

این سایت کاملاً Static است و به Node.js، پایگاه‌داده یا نصب بسته نرم‌افزاری نیاز ندارد.
ساختار پوشه‌های assets و data را تغییر ندهید.

تست روی کامپیوتر ویندوز:

اگر Python روی سیستم نصب است، روی فایل start-local.bat دوبار کلیک کنید.
مرورگر آدرس http://localhost:8000 را باز می‌کند.
برای پایان تست، پنجره مشکی را ببندید.

اگر Python ندارید، پوشه را در Visual Studio Code باز کنید و با افزونه Live Server فایل index.html را اجرا کنید.
فایل index.html را مستقیم با دوبارکلیک باز نکنید؛ در این حالت ممکن است مرورگر خواندن فایل‌های داده را مسدود کند.
